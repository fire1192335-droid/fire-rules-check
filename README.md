# 場所消防設備與無開口樓層法定判定系統

消防場所在案件規劃或竣工會勘階段用的**行政法規檢討**工具。輸入場所用途與樓層資料，快速判定應設消防安全設備與無開口樓層。

**線上使用**：https://fire1192335-droid.github.io/fire-rules-check/

> 姊妹專案：**消防竣工查驗現場核算系統**（泡沫、水系統、排煙、幫浦等現場實測計算）為另一獨立 App：https://fire1192335-droid.github.io/fire-inspection-calc/ 。本工具只處理法規檢討。

---

## 使用說明

1. 手機或電腦瀏覽器開啟網址。
2. 上方選單切換兩大模組。
3. 輸入資料，結果與判定會即時更新（也可按下方按鈕）。

### 安裝到手機（離線可用）

- **iPhone / Safari**：分享鈕 → 「加入主畫面」。
- **Android / Chrome**：右上選單 → 「加到主畫面／安裝應用程式」。
- 安裝後可離線使用。

## 模組與法規依據

> 以下為判定基準之來源方向；實際適用仍以主管機關公告之**現行法規**為準。

### 1. 各類場所應設消防安全設備自動檢核（含智慧用途判定）
- **智慧判定**：輸入如「咖啡廳」「集合住宅」「電子工廠」「老人長照中心」，自動對應甲／乙／丙／丁類目；判不出或有偏差時可用下拉選單手動校正。
- **檢核設備**：滅火器、室內消防栓、自動撒水、火警自動警報、手動報警、緊急廣播、標示設備、避難器具、緊急照明、排煙，分「滅火／警報／避難逃生／消防搶救」四大類，以綠（應設）／灰（免設）徽章呈現並標註條號。
- **法規依據**：各類場所消防安全設備設置標準 第 12 條（場所分類）、第 14、15、17、19、21、22、24、25、26、27、28 條。
- ⚠ 本模組為**簡化行政檢討輔助**，部分條文有例外與細目差異，實際仍應逐條核對現行法規。判定門檻集中於 [`data/constants.js`](data/constants.js) 之 `OCCUPANCY`。

### 2. 無開口樓層合規性判定（1/30 檢討）
- **有效開口**：須同時符合四條件（① 下端距地板 ≤120cm、② 面臨道路或 ≥1m 通路、③ 無柵欄且內部無阻礙、④ 可自外開啟／易破壞構造），否則有效面積以 0 計。
- **開口面積**：矩形 = 寬 × 高；圓形 = π × (D/2)²（寬度視為直徑）。
- **搶救用大型開口**：可內切直徑 ≥1m 圓孔，或 寬 ≥75cm 且 高 ≥120cm。
- **判定**：有效開口總面積 ÷ 樓地板面積 ≥ 1/30（約 3.33%）；10 層以下之樓層另需 ≥ 2 個搶救用大型開口。有一項未達即判為【無開口樓層】（紅燈）。
- **法規依據**：各類場所消防安全設備設置標準 第 4 條。

## 免責聲明

本工具之應設設備檢核為簡化行政檢討輔助，結果僅供規劃與初步判定參考，實際仍應由合格消防設備師（士）依現行法規逐條核對確認。

## 技術與維護

- 純靜態 PWA（HTML + CSS + 原生 JavaScript ES Modules），無打包工具、無後端。
- 判定門檻與類目集中於 [`data/constants.js`](data/constants.js)，修法時只需改此檔。
- 判定邏輯為純函式，位於 [`js/calc/`](js/calc)。

### 更新與重新部署

```bash
git add -A && git commit -m "更新說明"
git push
```

> 若異動了檔案清單或內容，請將 `sw.js` 的 `CACHE` 版本號往上調（例如 `fire-rules-v1` → `v2`），使用者才會取得新版。
